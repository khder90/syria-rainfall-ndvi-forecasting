# syria-rainfall-ndvi-forecasting
Reproducible code and data for long-term joint forecasting of rainfall and NDVI using time-varying multivariate systems.
The analysis includes:

- XGBoost
- XceptionTime
- Bayesian Time-Varying Parameter VAR with Stochastic Volatility
- Rolling-origin cross-validation
- Forecast horizons of 1, 3, 6, and 12 months
- Long-term forecasting through December 2030

## Reproduction

1. Download or clone this repository.
2. Keep `DATA.xlsx` in the same directory as the notebook.
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the environment installation cell when required.
5. Restart the kernel.
6. Run all notebook cells sequentially.
